# greenup-quotes

Cours de clôture quotidiens d'Onterris, Veolia, Séché Environnement, Lassila & Tikanoja et SciDev,
lus par le site GreenUp 2027 (EDHEC, groupe 5). Le fichier `quotes.json` est mis à jour chaque soir
de semaine par la tâche `.github/workflows/quotes.yml` (onglet Actions → Daily quotes → Run workflow
pour un relevé manuel). Source : Yahoo Finance, Alpha Vantage en secours ; le dernier cours connu est
conservé si les deux échouent.
